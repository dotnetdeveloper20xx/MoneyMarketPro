# Portfolio Demo Site Generator - Reusable Template

## 🎯 PURPOSE
Generate a polished, professional portfolio demo site that showcases a full-stack application to potential employers and clients. The output should be a self-contained static HTML site that sells technical skills through real code examples, visual diagrams, and impressive presentation.

## 🚀 EXECUTION APPROACH

### DO NOT use phased stop-and-wait approach. Instead:
1. Explore codebase thoroughly using an exploration agent
2. Read actual code files to extract real snippets
3. Generate ALL files in one session
4. Open in browser for user to review

### Key Principles:
- Base ALL content on ACTUAL code found - never invent features
- Include REAL code snippets with file paths
- Read 8-12 key files to get impressive examples
- Highlight what's genuinely impressive in the codebase

---

## 🔍 DISCOVERY PHASE

### Explore the Codebase For:

**Backend (adapt based on tech stack):**
- Architecture pattern (Clean Architecture, N-Tier, Vertical Slice, Hexagonal, etc.)
- Design patterns (Repository, CQRS, Mediator, Factory, Strategy, etc.)
- Domain entities, value objects, aggregates
- API controllers and routing structure
- Database/ORM setup and configurations
- Authentication/Authorization implementation
- Validation approach
- Error handling patterns
- Middleware, interceptors, filters

**Frontend (adapt based on framework):**
- Component architecture (standalone, modules, etc.)
- State management (Signals, NgRx, Redux, Zustand, Context, etc.)
- Routing and lazy loading
- HTTP interceptors/middleware
- Route guards/protection
- Form handling approach
- UI library/framework used

### Files to Read for Code Snippets:
Prioritize reading these types of files for impressive examples:
1. Base entity/aggregate root classes
2. Value objects with validation
3. Main domain entity (richest business logic)
4. CQRS command/query handlers or service classes
5. Validation pipeline/middleware
6. Auth service/JWT implementation
7. Database interceptors or middleware
8. Base controller or API patterns
9. Frontend auth/state service
10. Route guards
11. HTTP interceptors
12. A feature component showing patterns

## 💡 TIPS FOR EXCELLENCE

1. **Read Before Writing**: Read 8-12 actual code files before generating HTML
2. **Be Specific**: Use real class names, method names, file paths
3. **Show Don't Tell**: Code snippets > descriptions
4. **Visual Hierarchy**: Use icons, colors, and spacing effectively
5. **Sell the Skills**: Frame patterns in terms of why they matter
6. **Keep Snippets Focused**: 15-40 lines ideal, remove noise
7. **Consistent Voice**: Professional, confident, not arrogant
8. **Highlight Uniqueness**: If something is impressive, call it out
